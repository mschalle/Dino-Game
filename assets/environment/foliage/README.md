# Prepared jungle foliage

Nine normalized meshes generated by `tools/bake_foliage_meshes.gd`. Quaternius source models retain their CC0 license (`License_Standard.txt`); reeds are original project geometry. Meshes preserve imported LODs and original texture references, using the project's foliage shader.

Run Godot console with `--headless --path . --script res://tools/bake_foliage_meshes.gd` after changing source models, buffers, images, import settings, the shader or `jungle_dressing.gd`. Runtime uses file modification time/size stamps to avoid hashing large textures during gameplay. The roadmap gate verifies full content hashes and exact geometry/LOD/material/texture parity. A change that preserves file time and size requires the full validation gate to detect it. A fresh checkout may require rebaking local stamps; stale bakes fall back to source normalization, and missing source assets retain procedural fallback.

Compiled exports without raw scripts rely on bake version and the required pre-export validation gate. Do not mark packaged validation complete without testing exported resources.
